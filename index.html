Вход в систему

Последовательно подтвердите учётные записи Google и Steam. При первом входе профиль зарегистрируется автоматически.

Для защищённой регистрации нужно сначала подключить сервер авторизации.

Как включить вход и регистрацию

GitHub Pages публикует только статические файлы: он не проверяет Google и Steam и не хранит учётные записи. Здесь вход намеренно закрыт, а не заменён небезопасной имитацией.

  1. Разверните HTTPS-сервер авторизации с базой данных пользователей и защищёнными сессиями.
  2. Настройте Google OAuth в Google Cloud Console и Steam OpenID 2.0. Секреты и Steam API key храните только в переменных окружения сервера.
  3. После успешной проверки обоих профилей автоматически создайте пользователя и разрешите доступ. Привяжите HTTPS backend к этому сайту.
