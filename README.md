# Mandarin · оперативная база

Статический сайт для поиска по руководству Mandarin MediumRP и справочникам отдела. Архив источника распакован в `reference-source/`; используемые записи находятся в `assets/department-data.js`.

## Запуск

Из корневой папки проекта:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Сначала отображается обязательное окно входа; каталог намеренно закрыт без подтверждения Google **и** Steam сервером авторизации.

## Настройка регистрации

GitHub Pages публикует HTML, CSS и JavaScript, но **не запускает сервер и не проверяет OAuth**. Поэтому на странице нет фиктивной регистрации: кнопки пока сообщают, что требуется сервер. Первый успешный вход через обе учётные записи регистрирует пользователя автоматически; сайт не создаёт и не хранит пароли.

1. Разверните HTTPS backend, например Node.js-приложение на Render или Fly.io, с PostgreSQL для профилей и серверных сессий.
2. В Google Cloud Console создайте OAuth 2.0 Web Client. Укажите разрешённый адрес сайта и адрес возврата вида `https://AUTH-DOMAIN/auth/google/callback`. Сохраните Client ID и Client Secret только в переменных окружения сервера.
3. В настройках Steamworks задайте OpenID relying-party domain и адрес возврата вида `https://AUTH-DOMAIN/auth/steam/return`. Сохраните Steam API key только в переменных backend и проверяйте подпись OpenID 2.0 на сервере.
4. Реализуйте на backend маршруты `GET /auth/google`, `GET /auth/steam` и `GET /auth/session`, а также `POST /auth/logout`. Настройте callbacks Google и Steam. Храните проверенный Google `sub` и SteamID64 в одной записи PostgreSQL; создавайте запись после первого успешного подтверждения обоих профилей.
5. `GET /auth/session` должен возвращать `authenticated: true` и оба проверенных профиля только при действующей сессии. Используйте HTTPS, `HttpOnly`/`Secure` cookies, OAuth `state`, проверку OpenID и строгий список адресов возврата. Не принимайте решение о входе только на стороне браузера.
6. Установите публичный HTTPS-адрес backend в `authApiUrl` в `assets/site-config.js`. Разрешите credentialed CORS **только** для `https://den09hop87-hub.github.io`. Для сессий между разными доменами браузеры могут блокировать сторонние cookies; надёжнее подключить пользовательский домен к GitHub Pages, а backend разместить на его поддомене.
7. Добавьте Google Client Secret, Steam API key, URL PostgreSQL и секрет сессии в переменные окружения backend. Никогда не публикуйте их в GitHub, JavaScript, HTML или `site-config.js`.

Пока backend не подключён, кнопки входа специально не пропускают в каталог. Для действительно защищённых материалов одних скрытых вкладок недостаточно: приватные данные должны выдаваться backend по проверенной сессии, а не включаться в публичные файлы GitHub Pages.

## Данные

В архиве есть 28 документов руководства, 56 записей нарушителей и 27 записей ветеранов. Оригинального списка из 195 объявлений CASSIE со скриншота в архиве нет: поиск показывает настоящие подходящие документы и не подменяет утверждённые объявления вымышленными.

## Публикация

Для первой публикации в Settings → Pages выберите GitHub Actions как источник сборки. Текущий токен GitHub не разрешает включить Pages через API. После включения `.github/workflows/pages.yml` публикует сайт при каждом push в `main`.

Адрес сайта: https://den09hop87-hub.github.io/site6/.
